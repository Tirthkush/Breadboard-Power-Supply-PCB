# PCB Layout

This folder contains the **KiCad PCB layout** for the Breadboard Power Supply PCB.

The PCB layout was developed from the schematic and includes the **component placement, footprints, copper tracks, power connections, and board layout** for the 12V input, 5V regulation, and 3.3V regulation sections.

The PCB layout was designed with consideration for **component placement, routing, connectivity, and ease of assembly**.

**Software:** KiCad
