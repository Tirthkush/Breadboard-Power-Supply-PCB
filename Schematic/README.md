# Schematic

This folder contains the **KiCad schematic** for the Breadboard Power Supply PCB.

The schematic shows the complete electrical design of the board, including the **12V DC input, power switch, 5V regulation stage, 3.3V regulation stage, filtering capacitors, LED indicator, and output connections**.

The schematic serves as the electrical reference for the PCB layout and is used for component selection, footprint assignment, and PCB design.

**Software:** KiCad
