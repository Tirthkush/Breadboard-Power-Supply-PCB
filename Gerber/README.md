# Gerber Files

This folder contains the **Gerber manufacturing files** generated from the KiCad PCB design.

## Contents

The Gerber files contain the required manufacturing information for different PCB layers and features, including:

- Copper layers
- Solder mask
- Silkscreen
- Board outline
- Drill information

These files can be uploaded to a PCB fabrication service when the board is ready to be manufactured.

**Software:** KiCad

**Status:** Prepared for future PCB fabrication
