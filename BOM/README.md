# Bill of Materials (BOM)

This folder contains the **Bill of Materials (BOM)** for the Breadboard Power Supply PCB.

The BOM lists the components required for assembling the PCB, along with their **reference designators, values, footprints, and quantities**.

The BOM can be used as a reference for **component procurement and PCB assembly** when the board is fabricated.

**Software:** KiCad

**Status:** Prepared for future PCB assembly
